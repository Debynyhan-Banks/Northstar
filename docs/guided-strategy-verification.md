## Limits and manual inputs

Technical availability and qualifications are sourced manual entries. Models do not independently certify capability or establish launch readiness. Actual performance uses manual period totals or explicitly linked job records, with defined cost/period boundaries. Lifetime opportunity collections are never substituted for receipts in a reporting period. Financial outputs are management estimates, not an imported accounting ledger.

The website brief stays inside the authenticated planning workspace; no separate public company website or DNS changes are part of this release. The sign-in page displays only a general purpose statement. Live shared-account/source verification is separate from the local two-seat workflow and disposable SQL tests.
